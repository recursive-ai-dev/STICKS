# Cowboy Environment Generator

This project procedurally generates a variety of cowboy-themed environment sprites for 2D games. It creates both static and animated assets, offering a high degree of customization through code.

## Features

- **Procedural Generation**: Creates unique environment assets every time you run it.
- **Variety of Elements**: Generates a wide range of cowboy-themed items, including cacti, rocks, tumbleweeds, saloons, sheriff's offices, and more.
- **Animated Sprites**: Supports animated elements like tumbleweeds and campfires, outputting them as APNGs.
- **Sprite Sheet Generation**: Automatically creates sprite sheets for animations.
- **Customizable Palettes**: Uses a palette-based system for easy color scheme modifications.
- **Built-in Viewer**: Comes with an HTML viewer to easily inspect the generated assets.

## How It Works

The generation process is divided into three main scripts:

1.  **`cowboy_environment_generator.js`**: This is the core script that procedurally draws the environment elements onto a canvas. It generates multiple variations of each element and saves them as individual PNG frames in the `cowboy_environment` directory. For animated elements, it generates a sequence of frames.

2.  **`cowboy_apng_generator.js`**: This script takes the animated frames generated by the previous script and combines them into APNG (Animated PNG) files. The resulting APNGs are saved in the `cowboy_apng` directory.

3.  **`build_viewer.js`**: This script generates an HTML file named `viewer.html` that displays all the generated static and animated sprites. This makes it easy to preview the assets.

## Prerequisites

- [Node.js](https://nodejs.org/) (v14 or later recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/cowboy-environment-generator.git
    cd cowboy-environment-generator
    ```

2.  Install the dependencies:
    ```bash
    npm install
    ```

## Usage

1.  **Generate the environment assets**:
    ```bash
    node cowboy_environment_generator.js
    ```
    This will create the `cowboy_environment` directory and populate it with PNG frames.

2.  **Generate the animated PNGs**:
    ```bash
    node cowboy_apng_generator.js
    ```
    This will create the `cowboy_apng` directory and populate it with APNG animations.

3.  **Build the viewer**:
    ```bash
    node build_viewer.js
    ```
    This will generate the `viewer.html` file.

4.  **View the assets**:
    Start a local web server:
    ```bash
    npm start
    ```
    Then, open your browser and navigate to `http://localhost:8080/viewer.html`.

## Configuration

You can customize the generated assets by modifying the configuration variables at the top of `cowboy_environment_generator.js`. Some of the things you can change include:

- `SPRITE_SIZE`: The size of the generated sprites.
- `VARIATIONS`: The number of variations to generate for each element.
- `ENV_TYPES`: The list of environment elements to generate.
- `ANIMATED_TYPES`: The list of elements that should be animated.
- `FRAME_COUNT`: The number of frames for animations.
- `palettes`: The color palettes used for generation.

## Dependencies

- [canvas](https://www.npmjs.com/package/canvas): A library for drawing on a canvas, used for generating the sprites.
- [upng-js](https://www.npmjs.com/package/upng-js): A library for working with PNG files, used for creating the APNG animations.
- [http-server](https://www.npmjs.com/package/http-server): A simple, zero-configuration command-line HTTP server, used for viewing the generated assets.
